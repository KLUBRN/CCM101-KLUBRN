# Microsoft Azure Research

## Brief Overview
Microsoft Azure is a cloud computing platform developed by Microsoft and officially introduced in 2010. It provides cloud services for computing, storage, networking, databases, security, and application development. Azure is especially popular with businesses that already use Microsoft products.

## Global Infrastructure
Azure has a large global network of data centers and operates in more than 60 regions around the world. This allows businesses to deploy their applications in different locations and provide reliable services to users in various countries.

## Cloud Management Console
The Azure Portal is a web based dashboard used to manage Azure services and resources. Users can create virtual machines, manage storage, monitor resources, control subscriptions, and configure security settings through the portal.

## Four Core Services

1. **Azure Virtual Machines** — Provides virtual computers that can run applications and operating systems in the cloud.
2. **Azure Blob Storage** — Used to store large amounts of unstructured data such as documents, images, videos, and backups.
3. **Azure Virtual Network (VNet)** — Allows users to create private networks and control how their Azure resources communicate with each other.
4. **Microsoft Entra ID** — Provides identity and access management. It helps organizations manage users and control access to applications and cloud resources.

## Three Advantages

1. **Strong Microsoft Integration** — Azure works well with Microsoft 365, Windows Server, Active Directory, and other Microsoft products.
2. **Good Hybrid Cloud Support** — Azure provides tools such as Azure Arc that allow organizations to manage resources across cloud and on premises environments.
3. **Popular Enterprise Platform** — Many organizations use Azure because it works well with existing Microsoft based systems and business applications.

## Typical Enterprise Use Cases
- Connecting cloud services with existing on premises Windows systems
- Managing employee identities and access permissions
- Hosting enterprise applications and business systems
- Supporting applications such as SAP and Microsoft Dynamics 365
- Running virtual machines and other business workloads in the cloud
