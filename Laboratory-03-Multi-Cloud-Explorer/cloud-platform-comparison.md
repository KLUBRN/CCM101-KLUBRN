## Guide Questions

**1. Which cloud provider offers the broadest range of services?**
AWS offers a very large selection of cloud services. It has tools for computing, storage, databases, networking, security, and many other areas. This makes AWS suitable for different types of businesses and projects.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure has the strongest connection with Microsoft technologies. It works closely with products such as Windows Server, Microsoft 365, and Microsoft Entra ID. Because of this, Azure is a convenient option for organizations that already depend on Microsoft services.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud is a strong option for AI, machine learning, and Kubernetes. Google developed Kubernetes and provides Google Kubernetes Engine, or GKE, for managing containerized applications. It also has services such as Vertex AI for developing and deploying AI applications.

**4. Which cloud platform would you personally choose and why?**
I would choose Google Cloud Platform because I am interested in data, artificial intelligence, and modern application development. I think its tools for data analysis and machine learning would be useful for future projects. I also like that GCP provides Kubernetes services, which can help me learn more about deploying applications using containers.
