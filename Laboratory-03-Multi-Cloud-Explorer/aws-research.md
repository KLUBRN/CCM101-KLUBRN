# AWS Research

## Brief Overview
Amazon Web Services, commonly known as AWS, is a major cloud computing platform introduced by Amazon in 2006. It provides a wide variety of cloud services that businesses, organizations, and developers can use for computing, storage, networking, databases, and other IT needs.

## Global Infrastructure
AWS operates a large worldwide infrastructure made up of multiple geographic regions and Availability Zones. Its infrastructure is distributed across areas such as North America, Europe, Asia Pacific, South America, Africa, the Middle East, and other parts of the world. This allows users to deploy their applications closer to their customers and improve availability.

## Cloud Management Console
The AWS Management Console is a web based platform where users can access and control AWS services. Through the console, users can create resources, monitor services, manage security settings, check usage, and handle billing information.

## Four Core Services

1. **Amazon EC2** — Provides virtual machines that can be used to run applications and other workloads.
2. **Amazon S3** — A storage service used for saving files, documents, backups, images, videos, and other types of data.
3. **Amazon VPC** — Allows users to create and manage a private network for their AWS resources.
4. **AWS IAM** — Manages users, permissions, roles, and access to AWS resources to help maintain security.

## Three Advantages

1. **Wide Selection of Services** — AWS provides many different services that can support various IT and business requirements.
2. **Worldwide Availability** — Its global infrastructure makes it possible to deploy applications and services in different parts of the world.
3. **Strong Cloud Ecosystem** — AWS has many tools, partners, developers, and third party applications that work with its platform.

## Typical Enterprise Use Cases
- Running websites, mobile applications, and APIs
- Storing and analyzing large amounts of business data
- Creating backup systems and disaster recovery solutions
- Supporting business applications and company databases
- Hosting services that need to scale when user demand increases
