# Mission Reflection

## 1. How does a host based firewall protect a server even if the physical network perimeter is breached?

A host based firewall adds protection directly to the server. Even if someone gets past the main network security, the firewall can still filter connections based on the rules that were configured. This helps prevent unauthorized users from reaching services they should not access.

## 2. Why is managing open ports critical to reducing a server's attack surface?

Open ports allow different services to communicate with other devices, but they can also create security risks. If I leave ports open that are not needed, attackers may have more opportunities to find weaknesses in the server. That is why I should allow only the ports required for the server to work properly.

## 3. Why is it dangerous to leave a database port, like 3306 for MySQL, open to the public internet?

A database port that is open to everyone can attract attackers who want to access private information. They might try different passwords or take advantage of weaknesses in the database software. In my understanding, limiting database access to trusted systems is a safer way to protect important records.

## 4. How did this mission change your view of how easily a server can be compromised?

This activity made me realize that a server can become exposed when its security settings are not configured properly. Before this mission, I mainly focused on making applications work, but now I understand that protecting them is also important. I learned that even a working application needs proper firewall rules to reduce security risks.
