# Laboratory 09 Reflection

### 1. Why is automation critical when managing hundreds of cloud servers?

Automation helps cloud engineers manage many servers without repeating the same tasks manually. It saves time and allows scheduled tasks to run even when no one is available to start them. For example, a backup script can protect important files by creating copies automatically. I think automation is important because it makes daily server management easier and more organized.

### 2. What are the dangers of automation?

Automation can create serious problems if a script contains an incorrect command. For example, a command that accidentally removes important files could affect 1,000 servers if it runs on all of them. This could lead to data loss and service interruptions. Because of this, scripts should be reviewed and tested carefully before being used in a real environment.

### 3. How did writing a Bash script differ from writing the Docker Compose file in Lab 6?

In Lab 9, I used Bash to combine Linux commands into a script that creates and compresses backups. In Lab 6, Docker Compose was used to describe how the application and database containers should run together. Bash focuses on executing commands, while Docker Compose helps manage container services. Both tools reduce manual work in different ways.

### 4. How has your understanding of cloud computing changed from Lab 1 to Lab 9?

My understanding of cloud computing has grown throughout the nine laboratory activities. I learned that cloud computing involves more than storing files online. It also includes setting up infrastructure, deploying applications, managing data, monitoring servers, improving security, and automating tasks. These activities helped me understand how different cloud technologies work together to keep systems running properly.

The role I enjoyed most was Cloud Automation Engineer because I liked learning how to make tasks run automatically. Creating the backup script helped me understand how a simple program can perform useful work without repeated manual commands. I also learned that automation must be handled carefully to avoid mistakes. This experience made me more interested in learning how to improve server management through scripting.
