# Reflection on Cloud Computing 

After completing Laboratories 1 to 10, I gained a better understanding of cloud computing and how it is used in managing IT infrastructure. Before doing these activities, I had only a basic idea of how cloud services worked. As I continued with the laboratories, I learned about different technologies such as virtual machines, networking, databases, Docker, and security. These activities helped me understand that cloud computing requires different tools and services to work together properly.

One of the important lessons I learned was how to use Docker and Docker Compose to run applications and manage their services. At first, I had difficulty understanding how containers and images worked, especially when setting up WordPress and MySQL. As I practiced, I learned that each service has its own purpose and that Docker Compose helps manage them in one configuration file. I also realized that checking logs, reviewing configurations, and understanding error messages are important when something does not work as expected. Learning about firewall configuration also helped me understand why protecting a server and controlling network access are important parts of managing cloud infrastructure.

Laboratory 10 gave me an opportunity to apply what I had learned from the previous activities. Some tasks were challenging because I needed to solve problems without relying too much on detailed instructions. I experienced difficulties with commands, directory locations, GitHub, and service configurations. There were times when I did not immediately know what caused an error, so I had to review my steps and try different solutions. Through these experiences, I learned to be more patient and careful when working with technical tasks. I also understood that making mistakes is normal when learning new technologies, as long as I take the time to understand and correct them.

If I were assigned to create cloud infrastructure for an actual company, I would focus on making the system secure, stable, and easy to maintain. I would make sure that passwords and important credentials were protected, firewall rules were properly configured, and secure connections were enabled. I would also prepare regular backups to prevent data loss and use monitoring tools to check the condition of the system. If the company needed to support more users in the future, I would look for ways to increase its resources and automate some tasks to make the infrastructure more efficient.

Overall, Laboratories 1 to 10 helped me improve my knowledge and practical skills in cloud computing. Although some activities were difficult, they gave me a chance to practice using real tools and understand how different parts of an infrastructure operate. I realized that learning cloud computing is not only about memorizing commands but also about knowing how to apply them, analyze problems, and choose suitable solutions. These experiences encouraged me to continue improving my technical skills so I can become more prepared for future IT projects and responsibilities.
